# WDD 130 — Web Fundamentals

Coursework for **WDD 130 (BYU-Idaho)**, by Alonso Alvarado. This was the first
web course in the program, focused on semantic markup, layout and responsive
CSS rather than JavaScript.

Live site: https://alonso0099.github.io/wdd130/

## What's in this repo

### `wwr/` — Rafting Compas

The main course project: a four-page site for a fictional white-water rafting
company.

- `index.html` — home, with hero image and call to action
- `about.html` — company history and team
- `trips.html` — trip listings
- `contact.html` — contact form and location details

### Weekly exercises

- `week02/holygrail.html` — Holy Grail page layout
- `week03/wireframe.html` — wireframe practice
- `week03/overlay.html` — overlay and positioning practice
- `week05/poll-form.html` — HTML form and user poll

## Tech

- Semantic HTML5
- CSS3 — Flexbox and Grid layouts, custom properties for the color palette,
  responsive breakpoints
- No JavaScript frameworks and no build step
- Deployed with GitHub Pages
